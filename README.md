
# 🎓 SmartCampus

**SmartCampus** is an AI-powered student services platform designed to bring essential college information and student services together in one place.

🌐 **Live Website:** https://smartcampus-lemon.vercel.app/  
💻 **GitHub Repository:** https://github.com/Ganga-2508/SmartCampus  
🎥 **Demo Video:** https://youtu.be/iEv8ctQHuDU?si=W5Lb6SmigXxu9utj

---

## 📌 Problem Statement

Students often need to visit different sources to check attendance, class timetables, college notices, hostel and mess information, fee reminders, and administrative requests. Managing these activities separately can be inconvenient and time-consuming.

## 💡 Our Solution

SmartCampus provides a centralized web platform where students can access important campus information and manage common student services through a single interface.

## ✨ Key Features

- 📊 **Student Dashboard** — Access student services from one place.
- 📅 **Attendance Tracking** — View attendance information.
- 🗓️ **Class Timetable** — Check class schedules.
- 📢 **Campus Notices** — Access important announcements.
- 📝 **Complaint Management** — Submit complaints and track their status.
- 🏨 **Hostel & Mess Information** — Access hostel and mess-related information.
- 💰 **Fee Reminders** — Keep track of fee-related reminders.
- 🪪 **ID Card Requests** — Submit ID card-related requests.
- 🤖 **AI Student Assistant** — Interact with the student assistant using supported voice features.

## 🛠️ Tech Stack

- **Frontend:** React
- **Build Tool:** Vite
- **Backend & Data Services:** Supabase
- **Version Control:** Git and GitHub
- **Deployment:** Vercel

## 🏗️ How It Works

1. Students open the SmartCampus website.
2. The React interface provides access to available campus services.
3. Supabase supports the backend and data services configured for the application.
4. Vercel hosts the deployed web application.

## 🚀 Run Locally

### Prerequisites

- Node.js
- npm
- Required Supabase project configuration

### Installation

Clone the repository:

```bash
git clone https://github.com/Ganga-2508/SmartCampus.git
```

Navigate to the project folder:

```bash
cd SmartCampus
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL displayed in your terminal.

### 🔐 Environment Variables

If the application requires environment variables, configure them in a local `.env` file using the variable names expected by the project source code.

**Important:** Never commit passwords, access tokens, Supabase service-role keys, or other secrets to GitHub.
